# EvoTrace：基于蛋白质大模型的"数字定向进化"模拟器
## ——技术方案与实施计划 v1.0（2026-08-30）

> **一句话定位**：用户用自然语言描述一个环境（胁迫、离子、温度、pH、宿主……），系统在该环境映射出的适应度景观上，运行经进化生物学约束的深度学习进化引擎，模拟一条蛋白质在数千至数万年尺度下的完整进化轨迹，并输出谱系、关键突变事件、结构-功能解释与可信度区间——全程在硅内（in silico）完成，无需完全的湿实验验证。

---

## 1. 问题定义与科学定位

### 1.1 用户故事

输入示例：

> "让源自嗜热菌的碱性蛋白酶，在高盐碱地环境（5 M NaCl、pH 9.5、60 ℃、高浓度 Mg²⁺）中生存一万年，输出进化轨迹与候选优势突变体。"

系统需要产出：

1. **EnvSpec**：由自然语言编译出的结构化环境规范（机器可执行的适应度定义）；
2. **进化轨迹**：代际谱系树、突变事件流、等位基因频率动力学、平行进化/克隆干扰等进化现象；
3. **终点产物**：Top-K 优势变体（序列 + AlphaFold 级结构 + 各适应度分量 + 置信区间）；
4. **科学报告**：进化路径解释（哪个突变先发生、为何被选择、是否存在上位互作）、与天然进化的合理性比对。

### 1.2 科学问题分解

这件事本质上是把进化生物学的一个经典分解"搬进"深度学习框架。模拟 = 三个映射的叠加：

| 映射 | 内容 | 主要工具 |
|---|---|---|
| **M1：环境 → 适应度景观** | 把"5 M NaCl、pH 9.5"翻译成对每个候选序列的标量化适应度 | LLM 环境编译器 + 多目标代理模型 |
| **M2：基因型 → 适应度** | 序列/结构/功能预测，含上位性 | PLM（ESM 系列）+ 结构模型（Boltz-2/AF3）+ DMS 校准 |
| **M3：适应度 → 进化动力学** | 突变、选择、漂变、重组、瓶颈在种群中的展开 | 种群遗传学内核（Wright-Fisher/Moran），GPU 加速 |

现有工作分别推进了 M2（ESM-2/ESM-3、Tranception、EVE 等）和 M3（经典群体遗传学、FBA 数字进化），但**没有人把三者用"自然语言环境接口"缝合起来做长时程轨迹模拟**——这正是本方案的立足点，也是论文级创新点的来源。

### 1.3 与现有工作的差异

- 对比 **ProteinGym 类适应度预测器**（ESM-2/Tranception/EVE）：它们给单点/多点突变打分，不模拟时间、种群与谱系。
- 对比 **RFdiffusion/Chroma/ProGen 类生成模型**：它们采样"合理的蛋白"，但不回答"在这个环境压力下，谁会被选择、怎么一步步变"。
- 对比 **基于 FBA 的数字自适应实验室进化**（代谢网络层面）：在基因组/代谢尺度，不涉及蛋白序列的分子细节。
- 对比 **祖先序列重建（ASR）**：ASR 是回溯性的统计推断；我们是前向的动力学模拟，二者互为验证。

## 3. 关键设计决策与模块详设

### 3.1 环境编译器：自然语言 → EnvSpec（M1 映射）

用大语言模型做**函数调用式编译**，输出严格 schema 的 JSON，而非自由文本。EnvSpec 分三层：

```json
{
  "physics": {
    "temperature_C": 60, "pH": 9.5,
    "salts": [{"ion": "NaCl", "M": 5.0}, {"ion": "Mg2+", "mM": 50}],
    "oxidative_stress": true, "pressure_atm": 1, "solvent": "water"
  },
  "fitness_weights": {
    "stability": 0.30, "activity": 0.35, "halotolerance": 0.20,
    "solubility": 0.10, "expressibility": 0.05
  },
  "hard_gates": [
    {"property": "tm_C", "op": ">=", "value": 62},
    {"property": "solubility", "op": ">=", "value": 0.4}
  ],
  "dynamics": {
    "host": "Bacillus", "Ne": 1e5, "mutation_rate_per_site_per_gen": 1e-9,
    "generations_per_year": 300, "years": 10000,
    "events": [{"t_year": 4000, "type": "salt_ramp", "to_M": 5.0, "duration_y": 500}]
  },
  "safety": {"target_class": "industrial_protease", "allowed": true}
}
```

编译要点：
- LLM 只负责"语言 → 结构化参数 + 物理化学直觉标签"（如把"高盐碱地"映射到 halotolerance 权重上调、嗜盐菌表面酸性残基富集的先验），**不做任何数值预测**——数值全部由 3.2 的校准模型给出。这是防止"语言模型幻觉直接变成适应度"的关键隔离层。
- 每个物理参数绑定到**有据可依的适应度机制**（详见 3.2），无机制对应的参数（如"磁场"）由 LLM 显式标注 `mechanism: none, ignored`，并向用户披露。
- 提供交互式确认界面：用户可修改 EnvSpec 后再启动，保证可解释与可控。

### 3.2 适应度景观组装器：基因型 → 环境 - 适应度（M2 映射）

适应度 = 多分量加权和，且带硬性生存门槛（低于门槛适应度归零，模拟"死亡"）。每个分量选用当前最强的专用模型，并用 DMS 数据做蛋白家族级微调：

| 分量 | 首选 SOTA | 备选 | 校准数据 |
|---|---|---|---|
| 序列整体合理性/基线适应度 | ESM-3 (7B/98B) 或 ESM Cambrian 6B 的伪对数似然 | ESM-2 3B/15B、Tranception(带MSA)、PoET | ProteinGym 250+ DMS |
| 热稳定性 ΔTm/ΔΔG | RaSP 或 ThermoMPNN（结构输入） | PROSTATA、ESM 零样本 | ProTherm + 温度梯度 DMS |
| 活性/功能保持 | 家族级 PLM 微调头（EC/GO 多标签） | CLEAN、UniKP | BRENDA、UniProt 注释 |
| 配体/离子结合亲和 | Boltz-2（共折叠 + 亲和力，开源、可批量） | Chai-1、AlphaFold3（受限许可） | PDB、Binding MOAD |
| 嗜盐/离子胁迫 | 机制先验（表面酸性残基比例、盐桥密度）+ 家族内自然对比学习 | Boltz-2 离子结合项 | UniProt 嗜盐蛋白集、ProNIT |
| 可溶性/聚集 | CamSol 类序列模型 + 结构表面积分析 | NetSolP | 注释数据集 |
| 表达性 | 线粒体靶向/密码子适配性 + PLM 表达头 | — | eSol、表达 DMS |

三个关键机制设计：

1. **上位性来源**：纯加性模型会毁掉真实感。适应度主体用 PLM 伪对数似然（天然含高阶上位），叠加显式二阶项（Potts/DCA 耦合能量，从家族 MSA 拟合），再加**全局上位变换**（global epistasis，用单隐层网络把潜在适应度非线性映射到观测适应度——DMS 数据反复证明这一层存在）。三层结构：`f = g_epistasis(PLM + Potts + 特征项)`。
2. **嵌入缓存 = 万年模拟的可行性核心**：进化过程会遇到 10⁷–10⁸ 个独立基因型，但大量重复。做法：先离线对种子家族全 MSA 及其 1–2 突变邻域预计算 PLM 嵌入与结构特征建库；运行时新序列若未命中缓存才调用模型。真实突变率下，绝大多数世代步只做"查表 + 种群采样"，模型调用集中在缓存未命中的长尾。**这把万年模拟从"不可能"变成"单节点数天"**。
3. **不确定性量化与拒答**：每条序列的适应度输出 `(μ, σ)`。σ 来自模型集成（多个 PLM checkpoint + 两个结构系统交叉）与构象一致性（pLDDT、PAE）。长时程模拟中 σ 大的区域触发"保守选择"（等于给种群装上防走飞的安全带）。

### 3.3 变异提议器与"诚实 vs 加速"双模式（本方案最重要的方法论决策）

天然进化 = 随机突变 + 选择。如果直接让 PLM"提出聪明突变"，模拟就变成了优化器，失去了进化的统计性质。因此设两种模式，并给出混合方案：

- **诚实模式（Faithful）**：突变按物种特异替换谱（如对细菌用 Kosiol 等经验替换矩阵，或从近缘物种真实直系同源比对估计）均匀/按谱随机产生，适应度决定存亡。产出的轨迹可做严格的群体遗传学统计检验，适合发表级科学结论。速度由缓存决定。
- **加速模式（Accelerated）**：把 PLM 用作**提议分布**（proposal distribution）而非裁判——等价于对适应度景观上的定点分布做重要性采样/MCMC（如基于 PLM 逐位点重采样 + 重要性权重修正，或 HMC/扩散式序列采样）。**必须做重要性加权或 Metropolis 校正**，使轨迹的目标分布与诚实模式在数学上一致，只是方差/速度换效率。这样"快"不牺牲"对"。
- **混合策略**：默认诚实模式跑基线轨迹；当需要的世代数 × Ne 超出算力预算时自动切换加速模式并报告加速比与分布等价性检验（KS 检验两点突变谱、轨迹统计量对比）。

### 3.4 进化动力学内核（M3 映射）

不满足于"每代取 top-k"的遗传算法，内核实现真实的种群遗传过程：

- **繁殖模型**：Wright-Fisher（世代离散）与 Moran（连续时间）可切换；支持空间结构（岛屿/浅井模型）。
- **突变算子全谱**：点突变（物种替换谱）、短插入/缺失、串联重复滑移、**基因重复+新功能化**（打分函数分叉）、**结构域洗牌**（对多域蛋白，调用结构比对交换域）。
- **非双亲过程**：细菌的克隆干扰（clonal interference，Gerrish & Lenski 经典现象）用连续时间多突变谱系竞争实现；古菌/真核基因设重组开关。
- **事件脚本**：瓶颈（population crash）、迁移（引入外源同源蛋白基因流=HGT）、环境渐变/突变（如盐浓度 2000 年内线性上升 3 M——正是"气候变化式"胁迫叙事）、隐性等位与剂量效应。
- **平行系**：默认并行运行 N=8–32 个独立种群（复刻 Lenski 长期进化实验设计），输出平行进化统计（相同位点命中率的 P 值）——这既是科学必需，也是最便宜的自检。
- **GPU 实现**：种群状态编码为位矩阵，选择/漂变用 torch/CUDA 批量采样；单步 10⁶ 个体 × 500 aa 在单卡毫秒级。时间轴上的瓶颈点是缓存查表，不是模型调用。

### 3.5 时间尺度映射：代 ↔ 年

"一万年"需要显式换算假设并在报告中标明不确定性：

- 细菌：理论世代 20 min，但自然环境受营养限制，实测有效世代数 ≈ 6.6 代/年（Lenski LTEE 换算参考）到 ~10³ 代/年（富营养环境）；土壤/海洋寡营养取 10¹–10² 代/年。
- 报告层同时给出"代数"和"按三种世代时间假设换算的三条年轴"，避免把换算当成事实。
- 万年 × 10² 代/年 = 10⁶ 代 × Ne 10⁵：诚实模式下绝大多数基因型是缓存邻域内的重复，独立评估量约 10⁷–10⁸ 量级——见 3.2 的缓存预算，单节点数天可完成；加速模式再降 1–2 个数量级。

### 3.6 安全与防"景观博弈"门控

长时程优化器 + 代理模型 = 经典的 reward hacking 场景：进化可能收敛到"骗过代理模型"的怪序列。四道防线：

1. **OOD 惩罚**：序列偏离种子 MSA 超过阈值（如与最近自然同源序列的 Hamming 距离 > 家族内观测上限）时适应度乘以衰减因子——模拟"自然界可及性约束"。
2. **结构合理性硬门**：pLDDT < 70 或 PAE 网络异常的序列不得进入下一代的精英池。
3. **校准锚点**：定期用 DMS 实测值回灌，检测代理模型漂移。
4. **生物安全白名单**：EnvSpec 的 `safety` 字段由 LLM + 规则引擎双重审核；对毒素、病原体毒力因子、抗生素抗性增强等目标类别直接拒绝（拒绝逻辑独立于 LLM，规则引擎兜底），全程审计日志。

### 3.7 验证策略：五层"无湿实验"回溯验证

用户明确不需要完全实验验证，那么**可信度必须来自对"已知答案"的回溯预测**。这是本方案科学成立的支柱：

| 层 | 验证内容 | 通过标准 |
|---|---|---|
| **L1 单点保真** | 在 ProteinGym 250+ DMS 上评测适应度景观组装器 | Spearman ≥ 当前 PLM SOTA 均值，不劣化 |
| **L2 DMS 轨迹回放** | 在 GB1/avGFP/TEM-1 等有组合库或实验室进化实测的 DMS 上：以 WT 为种子跑 20–50 代模拟，比对实测富集轨迹 | 关键突变命中 Top-10%、轨迹相关 r>0.6 |
| **L3 自然进化回放** | 给家族 MSA"截断时间"（隐藏近期分支），前向模拟后与 ASR 重建的祖先序列及现存多样性比对（序列空间距离分布、二阶耦合统计） | 距离分布 KS 检验 p>0.05，Potts 统计一致 |
| **L4 文献案例对照** | 复现已发表的定向进化/自然适应案例（如嗜盐酶改造、耐热蛋白酶的经典突变组合） | 关键位点重现在 Top-K |
| **L5 平行一致性** | 多平行种群间统计：固定时间、突变谱、平行进化率与群体遗传学理论预测吻合 | 与 Wright-Fisher 解析近似一致 |

**科学诚实的表述**：系统定位是"假设生成器 + 进化合理性引擎"——它给出的是**校准过的、可量化不确定性的进化假说与候选序列**，而非"已验证的蛋白"。报告里每个 Top-K 变体都带 `(μ, σ)` 与 OOD 距离；同时强烈建议（但不强求）每轮 campaign 抽 12–24 条做最小湿实验点检，成本极低却能把系统性偏差暴露在早期。这个立场既是审稿人能接受的，也是"桂冠级"工作应有的严谨。

## 5. 算力与工程架构（概念估算）

- **训练**：不重训基础 PLM。做两件事：家族级 LoRA/Adapter 微调（单家族单卡小时级）；适应度头（多层感知机）训练。总训练需求 < 64 张 A100/H100 一次性投入。
- **推理主战场**：嵌入缓存构建（每家族 10⁷–10⁸ 序列 × 300 aa）。8×H100 节点按保守 500 序列/秒吞吐，1×10⁸ 序列 ≈ 2.3 天；10 个家族并行 ≈ 10 节点 × 3 天。此后运行期以查表为主，边际成本接近零。
- **结构门控**：Boltz-2/ESMFold 只对精英池（每代 10³–10⁴ 条）调用，是二级瓶颈，可按需扩容。
- **工程栈**：PyTorch + FSDP；内核用 CUDA/torch.compile；缓存用 Milvus/FAISS 向量库 + Redis 热层；编排用 Ray；前端 FastAPI + React（EnvSpec 交互编辑器 + 谱系可视化，用 ECharts/icytree 类树渲染）。
- **可复现性**：每次运行的随机种子、模型版本、数据版本、EnvSpec 全部哈希入库，轨迹可精确重放——科研工具的生命线。

## 7. 风险与对策

| 风险 | 概率 | 影响 | 对策 |
