## 1. 最初目的（不可漂移的北极星）

来源：`reference/蛋白定向进化模拟器_技术方案_v1.md` 第 0 节"一句话定位"，原文照录：

> 用户用自然语言描述一个环境（胁迫、离子、温度、pH、宿主……），系统在该环境映射出的
> 适应度景观上，运行经进化生物学约束的深度学习进化引擎，模拟一条蛋白质在数千至数万年
> 尺度下的完整进化轨迹，并输出谱系、关键突变事件、结构-功能解释与可信度区间——
> 全程在硅内完成，无需完全的湿实验验证。

由此派生的四条验收线（后续所有工作必须能回答"这推进了哪一条"）：

1. **环境条件 → EnvSpec**：用户从预设环境选项中选择并自行输入条件参数，生成机器可执行的
   适应度规范（v1 §3.1 结构；2026-09-05 拍板：~~自然语言 LLM 编译~~ 改为预设库 + 自输
   条件，无机制参数硬校验拒绝）。
2. **长时程轨迹**：万年级、10⁴–10⁶ 代的进化动力学模拟，而非十几代的优化循环（v1 §3.4–3.5）。
3. **进化产物**：谱系树、突变事件时间线、平行进化统计、进化叙事报告（v1 §1.1 用户故事 2/4）。
4. **无湿实验可信度**：五层回溯验证（L1 ProteinGym / L2 DMS 回放 / L3 自然进化回放 /
   L4 文献案例 / L5 平行一致性）（v1 §3.7）。

## 3. 改回方案：目录与边界

**原则一**：主线（模拟器）与战役（PprI/nom2 等具体课题）物理分离，campaign 不再往
`evo2/` 里塞代码。
**原则二**：不删任何东西——战役是真实科学记录（n=100 判决、F88R 等结论有湿实验价值），
只归档、只搬家。
**原则三**：主线代码进 `evo2/` 时必须带 v1 验收线编号（本文件 §1 的 1–4），否则不合入。
