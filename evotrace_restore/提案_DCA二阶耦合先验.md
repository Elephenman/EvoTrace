# 机制提案 — DCA 二阶耦合先验（R4 后续, 提案门送审稿）

> 2026-09-06。四段式（实战问题 → 证据 → 一般机制 → 落点模块）。
> 状态：**b10 验证实验已跑**，判决与证据表见 §2；待评审决定是否进 engine。

## 1. 实战问题（为什么需要这个机制）

b9（L3 自然进化回放, R4）两家族双不过，失败模式清晰且可复现：

- **多样性封顶**：逐位点独立 PSSM 景观的混合平衡距离被自身 PSSM 熵结构性封顶。
  A4/HUMAN 实证：回放平衡距离 ~0.42，够不到祖先侧实测 0.77；
- **无亚家族结构**：NEIME 组内距离分布形状 KS D=0.422——独立位点模型
  原则上无法产生自然 MSA 的耦合聚类（分布形状）。

v1 通过标准（§3.7 L3）要求"距离分布 KS p>0.05 + Potts 二阶统计一致"——
逐位点先验在数学上就不可能满足第二条。**这不是调参问题，是模型类问题。**

## 2. 证据（b10 验证实验, 2026-09-06, 本地 + CPU 集群）

方法：伪似然 DCA（逐位点 L2 正则 softmax 回归 = plmDCA 标准 v0）在祖先半
（N=2000 子样）上拟合条件分布 → Gibbs 平衡采样 → 与 b9 同口径比对。
脚本 `evo2/benchmarks/b10_potts_coupling.py`，报告 `evo2/results/b10_potts/`。

| 家族 | λ | 模拟均值 | 祖先实测 | 组内 KS | 熵 rho | 来源 |
|---|---|---|---|---|---|---|
| A4_HUMAN | 0.01 | **0.805** | 0.829 | p=0.0181（最好） | — | 本地 |
| A4_HUMAN | 0.1 | 0.940（过冲） | 0.829 | D=0.289, p=5.4e-74 | +0.238 | 集群 36s |
| NEIME | 0.01 | 0.133（塌缩） | 0.357 | p≈0 | +0.317 | 本地 |
| NEIME | 0.2 | 0.950（过冲） | 0.359 | D=0.977, p≈0 | −0.011 | 集群 48s |
| NEIME | 0.5 | 0.949（过冲） | 0.357 | p≈0 | — | 本地 |

（b9 PSSM 基线对照：A4 组内 D=0.780 / 均值封顶 0.42；NEIME D=0.422。）

**已确立的结论**：
1. **熵封顶假设成立**：二阶耦合把 A4_HUMAN 的回放平衡距离从 PSSM 封顶的
   ~0.42 恢复到 0.805–0.940（实测 0.829），且 λ 可调——b9 判决的根因
   （逐位点模型类的多样性上限）得到反事实验证；
2. **分布形状全线不过**：均值能校准，但 KS p 全部 ≤0.0181（大样本下
   p≈0），最好 D=0.289（A4 λ=0.1）——均匀 Potts 的平衡分布没有
   复现自然 MSA 的亚家族聚类形状；
3. **λ 是有效耦合密度的旋钮，双向敏感**：NEIME 0.01 塌缩 / 0.2–0.5 过冲
   ——需要训练侧校准协议（同 b9 的 T 校准思路）；
4. 判决：**REVIEW，但机制方向确认**——"二阶耦合是均值多样性的必要条件"
   成立；L3 全过线还差分布形状 → 下一杠杆是 v1 §3.4 的第二个必要条件
   **空间结构（岛屿模型）**，或推断升级（APC 校正、增大拟合子样）。

工程备注：集群（10.205.1.3, esm3 env）单组 36–48s，比本地（内存受限换页）
快 ~20 倍；部署走 `evo2/cluster/ssh_cpu.py` + a2m 目录模式（b10 自带,
1.5GB zip 不出本地）。

## 3. 一般机制（提炼后是什么）

**"逐位点独立先验"与"耦合先验"是两个模型类，能力边界由目标分布的
统计阶数决定**：当验证目标涉及高阶统计量（亚家族聚类、耦合锁定、
多样性形状）时，低阶模型类无论怎么调参都不可达——必须升级模型类，
而不是在低阶类内扫参数。这条判据可复用：任何"基准不过线"的诊断都应
先问"目标统计量的阶数 vs 模型类的阶数"，再谈调参。

（此教训与 v7 sep 失败同构：DL 只学了基因型总体 act，条件构造不要求学
S1/OFF 之差——目标统计量与训练目标错位。两次独立证据，建议入设计约束库。）

## 4. 落点模块（过门后去哪）

1. `evo2/engine/potts.py`（新增）：PlmDCA 拟合器 + 条件分布 Gibbs 采样器 +
   λ 训练侧校准（在祖先半上把平衡多样性校准到实测）；
2. **岛屿模型同批进**（b10 结论 2 的直接推论）：形状缺口需要空间结构补，
   单独接入 Potts 不可能过 L3——`run_with_events` 的 n_pop 天然就是岛，
   差的是"岛间迁移率 < 全局混合"的动力学参数与岛内耦合提议；
3. kernel 接入：变异提议从逐位点 `prior_table` 升级为条件分布
   P(x_i | x_rest)（联合提议），`WFKernel` 对外接口（run/events/observer）
   零改动——事件脚本、平行系、fitcache 不受影响；
4. b9 复跑：接入后 L3 协议原样重跑两家族，出口标准不变（KS p>0.05）；
5. 不做：真实 ASR 截断代理升级（另案）、温度调节（**见 §4.5, 仅指 Potts 推断温度不做; WF 选择温度校准照 b9 口径**）、APC 校正（v1 门后再议）。

### 4.5 温度调节口径（P2-3①）

落点第 1 项 `potts.py` 的"λ 训练侧校准"与第 5 项"不做：温度调节"中的
**"温度调节"特指 Potts 推断温度（DCA 拟合的热力学温度）不做**——plmDCA
在 `T=1` 固定下拟合条件分布, 不引入推断侧退火/温度扫描。**WF 选择温度
`T` 校准（softmax(E/T) 的选择强度）属 b9 原口径, 照做**, 不在本提案重新论证;
b11 的 `T 校准`步骤直接复用 b9 的训练侧校准逻辑（目标 = 祖先侧实测平衡距离）。
二者不可混淆: 前者是"推断温度", 后者是"选择温度"。

### 4.6 落点顺序说明（P2-3②）

### 4.8 框架偏差留痕（2026-09-07, 用户裁定"先跑完再优"）

b10/potts.py/b11 现为 **numpy 实现**——偏离 v1 §工程栈的 PyTorch 约定。
起因: b10 按小时级过门验证 v0 起步直写 numpy, 下游沿用; 未显式立项说明,
属过程疏漏。性能事实: 耗时大头是 WF 回放算法规模（λ/T/m 网格 × 代际模拟
+ 终跑 2000 代×8群×Ne=500）, torch-CPU 对小张量逐代循环无实质收益;
torch 的正确生效点是 **GPU 批量化**（种群位矩阵 × 网格回放并行）。

**裁定**: 当前 b11 两家族跑完出判决（数值与框架无关）; torch 化与 GPU
批量化**并入 §4.2/§4.3 的 engine 集成阶段**统一实施（v1 工程栈在该阶段
生效; 届时评估 4090D/CHPC gpu 分区可用性）。若过门前需提速, 备选 =
网格回放 multiprocessing 并行（纯 numpy, ~4-8×, 需停跑重跑+复审）。

### 4.9 协议修正: gap 膨胀诊断与三项修复（2026-09-07, 用户批准）

**诊断**（集群 30 代复现, scratch/diag_gap.py）: anc21 把 gap 当正经状态(20)
拟合 → MSA gap 富集位点的场强偏好 gap → WF 选择的 softmax(E/T) 在 T_REF=1.0
下**第 1 代即 gap 固定**（12.7%→99.99%, rows≥5 非掩码位点 95%→0%）→
pair_distances 永远凑不满样本对（0/400）→ 无限空转（b11 首跑 10.5h 的全部去向）。
island_wf 本身仅 0.02s/代——b11 慢不是性能问题, 是协议缺陷。性能归因修正:
§4.8 的"回放算法规模"说法作废, numpy 原速已足够（终跑 ~7 分钟）。

**三项修复**:
1. **gap 退出变异字母表**: island_wf 新增 proposal_states 参数, 条件分布在
   20 AA 上重归一化（禁止态质量全占的行回退均匀分布）; 祖先既有 gap 保留。
   理据: gap 是比对伪迹, 不是演化状态, 不应被选择奖励。
2. **λ×T 联合校准**（注: §4.10 已将其扩展为 λ×λ_mut×T 三维, 见下节）: 原"先 λ(固定 T=1)后 T"顺序在 T=1 必然退化 → 改为
   λ∈LAM_GRID × T∈T_GRID 全组合祖先侧短回放, 按 |均值−祖先实测| 选优;
   每 (λ,T) 组合先过退化守卫。联合搜索同时消解 P2-2"m 被钉死"的部分顾虑
   （λ/T 不再序列化决策; m 仍后置）。
3. **退化守卫**: run_mean_dist 返回 None（<50% 样本对有效）; 全部组合退化
   → 显式失败退出; sample_pair_dists 替换判决路径的 pair_distances
   （500× 尝试上限, 凑不满即抛错, 永不空转）。

**纪律不变**: 校准全部祖先侧、盲测零泄漏、判决三条件不动、island_wf
契约不变（proposal_states 默认 None=原行为, 39 测试全绿）。

### 4.10 协议修订: 混合制 + λ_mut 校准（2026-09-07, 用户批准"不用 GPU 顺便跑"）

**诊断链第三层**: fitness 变体对照探针（scratch/probe_fitness.py, A4 家族,
全祖先侧）证明——①plmDCA 能量作 WF 适应度被 gap 劫持（corr(E,gap数)
=+0.94~0.99, 4λ×8T 全网格 71/96 组合退化, 唯一"达标"组合选出的高适应
序列=gap 汤, 科学上空）; ②非 gap 能量/祖先对数先验两变体全程零退化
（pass 1.00）, 伪迹解除; ③两变体回放均值 0.01–0.32 << 祖先实测 0.825
→ **λ_mut=0.3 突变供给不足**（b9 自然回放 ≤12 次/基因组/代, 40×）是
第三层独立根因, 600 代漂移压扁初始多样性。

**修订**:
1. **适应度 = 祖先对数先验**（b9 式 PSSM 口径, 但为 **Laplace 平滑变体:
   log((counts+0.5)/(sum+0.5·Q)), 异于 b9.pssm_prior 的实现（pseudo=1.0 加性
   平滑, 仅 20 AA、gap 不计, 归一化后概率下限 1e-3）**,
   含 gap=20 态）
   ——回归提案 §4.2 原意"只升级变异提议, 不换选择机制"; P2-4 的"能量作
   适应度"声明**被实验否决**, 撤销; Potts 能量降级为诊断量。
2. **λ_mut 入校准网格** {0.3, 2, 6, 12}（对齐 b9 自然回放口径）, 与
   λ×T 三维联合（祖先侧）, 按 |回放均值−祖先实测| 选优。
3. 判决三条件、盲测纪律、退化守卫、proposal_states 全部不变。

预期: 校准 ~25 min + m 选择 + 终跑 ~7 min → 双家族判决当日出。
