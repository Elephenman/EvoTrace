## R4 — L3 自然进化回放（对应 v1 §3.7，验收线 4）

五层验证中 L1/L2/L5 已有基准，缺 L3：给家族 MSA"截断时间"，前向模拟后与 ASR 重建
祖先及现存多样性比对（距离分布 KS 检验、Potts 二阶统计）。

1. 选一个 MSA 充足的家族（avGFP 或枯草杆菌蛋白酶，v1 附录建议的锚点家族）。
2. 截断回放 + KS/Potts 比对脚本，进 `evo2/benchmarks/b8_natreplay.py`。

**出口标准**：距离分布 KS p>0.05、二阶耦合统计一致（v1 通过标准），或如实记录失败
并分析原因。

**2026-09-06 执行（b9_natreplay.py, 两家族）→ 判决 REVIEW, 失败归因清晰**：
- 协议: ProteinGym MSA（195 家族可用）→ 共识距离截断二分（v0 代理, 非 ASR）→
  ancestral 半 PSSM 先验 + **选择温度在训练侧校准**（不拍脑袋）→ WF 2000 代 × 8 群 →
  三方 KS（盲测 derived / 组内 ancestral / 全 MSA 参考）。
- NEIME 家族: 均值可达标但分布形状不过（组内 D=0.422）——无亚家族聚类结构;
  A4/HUMAN 家族: 平衡距离被 PSSM 熵上界钉死 0.42, 够不到祖先实测 0.77——
  **逐位点独立景观的多样性上限是自身 PSSM 熵, 结构性封顶**。
- 结论: L3 通过的必要条件 = Potts/DCA 二阶耦合（v1 §3.2）+ 空间结构种群（v1 §3.4
  岛屿模型）——负结果本身是这两项需求的实证, 已列为 R4 后续（DCA 推断单独立项）。
- 教训入库: n_mut_max 是战役设计约束, 自然回放须放开（否则多样性被硬压 ≤12/K）。

**R4 后续 b10（2026-09-06, DCA 二阶耦合 + Potts 平衡采样）→ REVIEW, 机制方向确认**：
- 伪似然 DCA（逐位点 L2 正则 softmax）+ Gibbs 平衡采样, 两家族 × λ 扫描
  （本地 + CPU 集群, `b10_potts_coupling.py`, 提案 `提案_DCA二阶耦合先验.md`）；
- **熵封顶解锁确认**：A4_HUMAN 回放均值 0.42（PSSM 封顶）→ 0.805–0.940
  （实测 0.829, λ 可调）——b9 根因"模型类阶数不足"反事实验证；
- **形状全线不过**：KS p ≤0.0181（最好 D=0.289）——均匀 Potts 无亚家族
  聚类形状 → 下一杠杆 = 岛屿模型（v1 §3.4 第二必要条件）与 Potts 联合接入；
- λ 双向敏感（NEIME 0.01 塌缩 / 0.2+ 过冲）→ 训练侧校准协议随 potts.py 立项。
