## 0. 一句话

EvoTrace 是一套**"进化筛选 → 结构复核 → MD/湿实验验证"的闭环蛋白设计工具**：用实测/结构
先验驱动 Wright-Fisher 数字进化产生候选，再用条件特异性模型排序，最后用 Boltz-2 + Amber MD
把"候选"验证成"对特异 ssDNA 高结合、对非特异 ssDNA 不结合"的可实验蛋白。整套方法学已跑通
并**自我纠错**（推翻了多个由抽样噪声造成的假阳最优）。

### 1.1 L1 引擎的五机制（从 PprI 战役教训逆向映射，全部可消融）
- **M1 稳定性修正先验**：`prior'' ∝ prior' × exp(−ΔΔG/τ)`，τ=2 kcal/mol。教训：几何/化学先验
  有系统性盲区（低估芳香 π-stack，PprI 135H +8.55 kcal/mol、88Q +2.67）。
- **M2 锚位族约束**：位点类 anchor 时，突变只允许在结构化学族内（芳香族 / 疏水族），跨族禁止。
  教训：进化反复破坏 88/135/171 芳香锚。
- **M3 稳定性入适应度**：`f = Σs(i,a) + w_stab·(−ΔΔĜ)`。教训：早期漏斗放行 +15~17 kcal/mol 去稳定冠军。
- **M4 贝叶斯标签回流**：`prior' ∝ prior^(1−α) × Laplace 后验^α`。教训：Phase-1 黑箱特征蒸馏
  失败（LOOCV ρ=0.06）→ 放弃黑箱，保留可解释伪计数主动学习。
- **M5 层级漏斗**：cheap(先验核) → mid(PLM ΔLL) → expensive(Boltz 结构) 三级 + 硬门槛。
  教训：廉价/昂贵层分层有效但无理论刻画。

### 1.2 L2 预测器谱系（当前工具的核心判定器）
- **v4（经典最优，当前在役）**：`train_sep_model_v4.py`。条件特异性模型，输入 = 基因型 + DNA 条件。
  - 特征：9 分类（rh66/m255/y217/锚位态/碱基 nt10/17/23/cond…）+ 8 数值
    （n_mut / 位点簇计数 lock·anchor·cat / 电荷 / 代理 z），one-hot 后约 160 维。
  - 位点簇定义（PDB 编号）：readhead 88 / lock 253·217·255 / anchor 85·207·267 / cat 92·93·96·123。
  - 模型：RidgeCV + HistGBM；验证 = **按系统 LOO**（预测未见系统）。
  - 判决口：V1 act/dual/dcat Spearman、V1b 靶/非靶 sep、V2 deconf-22、V3 V2-A 上位性留出。
- **v5/v6 DL**：三篇文献 transformer 架构 + 变体专属 ESM3 表征 → 在**旧噪声标签**上均输 v4。
- **v7（判决中）**：`train_dl_v7_par.py`。= **v6 架构（变体专属 token + 全局向量 + PCA 上下文）×
  n100 干净标签**，DL 公平重测。37 折系统 LOO，线程并行 + 断点续跑（主 ckpt + worker ckpt）。
  判决基线 = v4@n100：act +0.739 / dual +0.747 / sep +0.330 / 符号 0.92。
- **evoprior.py（v3 草案，引擎层的"自然先验"方向）**：MSA → PSSM(标签) → ESM-2/ProtBERT
  逐残基嵌入(输入) → 轻量 MLP → 每位置 20 维天然偏好 p_evo；与化学先验融合
  `p_final = α·p_chem + (1−α)·p_evo`，α 交叉验证学习（最小化 KL(p_ssm‖p_final)）。
  价值：自动识别并规避"手工规则盲点"（如 PprI 135 位 p_evo 偏好疏水 M/F/L → 纠正 M135H）。
  代码注释里保留了一个历史 bug 教训：a3m 必须保留 `-`（gap），曾用 `c.isupper()` 过滤把 gap
  一起剔除导致 PSSM 退化。

## 2. 构建方法（端到端数据 → 候选流水线）

```
结构先验 priors.csv ──┐
WT fasta + MSA ───────┼→ WFKernel 数字进化 ── 精英候选
FoldX ΔΔG 实测 ───────┘        │
                    propose_elites(top-k + Hamming 多样性)
                               │
                    ┌──────────┴───────────┐
                    v4 条件特异性模型排序    条件(A) Boltz-2 yaml(蛋白+DNA+Mn²⁺)
                    (GBM/Ridge LOO)         条件(T) 非靶 ssDNA
                    └──────────┬───────────┘
                               ▼
                 接触指纹判读器：HEXXH接触(act) · 双锁K67-G17/R232-T23(dual) · sep=act(S1)−act(OFF)
                               │
                          n100 复核（Boltz ×100/条件，V100 5.3s/model，~1.4h）
                               │
                    MD 4 变体清单 → Amber pmemd.cuda 生产 → MMPBSA ΔG_spec → 湿实验提名
```

- **判读铁律（记忆固化）**：HEXXH(seq71-75) 接触为"激活"、K67-G17/R232-T23 ≤5Å 为"双锁"、
  sep = act(S1)−act(OFF)；序列索引 = PDB − 21（表尾 seq=PDB−22 与判读 21 的差异须分清，nom2 用 −22）。
- **n100 精度重扫**：把 n=8/20 的噪声标签（二项噪声 95% 半宽 ±0.30）换成 n=100 干净标签。
  boltz 2.2.1 需 `--no_kernels`（4090 触发 cuEquivariance）、MSA 走 `msa_a3m` 离线、`mols.tar` 缓存。
- **版本漂移校核**：六候选 2.0.x(n=20) vs 2.2.1(n=100) act/dual 漂移 0.090/0.087 —— 在抽样噪声内，无系统偏差。

## 3. 优点（有硬证据的，非宣传）

1. **方法论自我纠错机制健全**：n100 重扫推翻 V2-A（M255I 在两背景均负）、平反 F88R 单点
   （+0.50/dual 0.53 全场最优）、证伪 F88W 在 WT 的假阳（n=8 第3→n=100 垫底 0.10）。工具"知道怎么
   不被自己的噪声骗"，这是多数管线没有的品质。
2. **标签经济性实证强**：avGFP ρ=0.512@384 标签、GB1 0.707@1536 超过 1.4B ESM3 零样本
   （0.251/0.469）；TEM-1 16/16 全胜。在"实测景观"上证明结构先验+进化核+标签回流能以数百标签
   超大型 PLM 零样本。
3. **特异性可解释、可判读**：不只看 sep 数字，拆成 act（催化口袋接触）/dual（双锁锚定）/
   OFF 排斥，每个指标对应用户"对特异结合+对非特异不结合"的物理语义。
4. **工程健壮性**：种群 `int8[Ne,L]` 全向量化、LOO 断点续跑（主 ckpt+worker ckpt 双落盘）、
   全固定种子可复现、报告自动生成 markdown、离线 MSA 管线避免外网依赖。
5. **大规模验证成本已打通**：V100 5.3s/model、n100 复核 ~1.4h 完成 7400 模型、8 分片并行 0 失败；
   可复用判读器与扫描脚本。

## 4. 缺点与踩坑（从代码注释 + 实战挖出的真实教训）

| # | 缺点 / 风险 | 证据 / 场景 | 影响 |
|---|---|---|---|
| D1 | **小型号标签信噪比极低** | n=8/20 二项噪声 95% 半宽 ±0.30；n=100 复核推翻多个"最优"（M255I、F88W、HQL2 sep 0.07 无选择性） | 早期大半结论须重判；浪费了多轮提名 |
| D2 | **DL 至今未赢经典模型** | v5/v6 transformer 在噪声标签上均输 v4 GBM/Ridge；v7 判决未落地 | "v4 仍是冠军"的表述保守但有据；DL 价值待裁决 |
| D3 | **v7 进程反复中断** | loo_ckpt f0-f16 完成（含 (2,3) 紧凑 te 切片，f17-f36 未跑），进程在会话关闭/内存瓶颈(页面文件 ~5.8GB)处被杀 | 判决长期悬置（已用断点续跑修复，见 §6） |
| D4 | **Windows 内存墙** | 多进程 torch 撑爆页面文件 WinError 1455 → 被迫改线程并行 N_THREADS=2 | 大折并行慢（~340s/折） |
| D5 | **sep top10 脆弱** | n100 REPORT：sep 全量 +0.330，但 top10 −0.414（大 sep 系统小样本，单系统错排即翻转） | 大分离候选排序不可靠，须 n100 复核兜底 |
| D6 | **先验易成盲区，且跨蛋白重现** | PprI 135H ↔ avGFP K158G：机制先验盲区在不同蛋白重复出现 | 印证"先验必须可被数据修正"是设计公理 |
| D7 | **多代工具版本交错易混数据** | w4 权威序列=12mut（22R…265S），但 all_candidate_sequences.json/w4_seqs.tsv 是脏数据（KAPAK 错误版）；HQL2 的 pred 命名跨文件不一致（w_HQL2/w4 旧批） | 引用错序列会导致整条战役废掉，需严格版本钉死 |
| D8 | **网格/集群运维耦合高** | CHPC 权限变更（gpu 分区 9/3 收回 ls_lhz）、NFS 挂载点探针盲区（/users vs /home）、sftp put 不稳 | 环境脚本易碎，探针必须先 df -h 查挂载 |
| D9 | **方法论文的诚实边界** | PprI 全为计算代理（Boltz sep / FoldX ΔΔG_pred），未湿实验；avGFP"昂贵标签"=DMS 实测本身 | Claims 只能限定在"标签经济性"，不能声称绝对预测精度 |
