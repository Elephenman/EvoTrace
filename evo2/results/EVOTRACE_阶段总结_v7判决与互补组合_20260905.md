## 2. v7 判决（9/5 凌晨，37 折 LOO 全跑完）→ **REVIEW，DL 首胜 act/dual 但败 sep**

| 指标 | **v7 DL** | v4@n100 基准 | 判定 |
|---|---|---|---|
| V1 act | **+0.770** | +0.739 | ✓ 超 |
| V1 dual | **+0.838** | +0.747 | ✓ 大幅超 |
| V1 dcat | **+0.748** | — | ✓ |
| **V1b sep** | **−0.124** | **+0.330** | ✗ 显著差 |

- **首次**：DL 在 act/dual/dcat 三项标签精度全部超越 v4（此前 v5/v6 在噪声标签上一直输）。
  证明"之前 DL 输，是被 n=8/20 噪声标签害的，不是架构不行"——换 n100 干净标签后 DL 反转。
- **但 sep（靶/非靶分离）彻底失败**（rho −0.124 vs v4 +0.330）。sep 是特异性核心判据，
  故整体判决 REVIEW。
- 关键结论：**v4 仍是 sep(特异性)冠军，DL 的价值在标签(结合强度)拟合**。

## 3. sep 失败根因诊断 + 两版改造 A/B（用户拍板"A1+A2 都做"）

**根因**（读源码确认）：DL 只被要求学"基因型总体 act"，DNA 条件（S1 vs OFF）只经
global_vec 的 3 碱基 one-hot + 24bp query cross-attention 弱旁路进入，**从不被显式要求
学 S1/OFF 的 act 之差（即 sep）**。

| 模式 | sep rho | 结论 |
|---|---|---|
| v7 原版（基线） | −0.124 | 学不出 |
| **A1：显式 sep 对比目标** | ep12 **+0.127** / ep24 **+0.008** | 方向对、翻正，但不稳、强度不足 |
| A2：条件前置交叉 | −0.147 | 无效，排除 |

- A1 全量（ep24）完整：act +0.761 / dual +0.850（**保住且仍超 v4/v7**）｜ sep +0.008。
- **判定**：加 sep 损失确能让 DL 学到 sep 方向（符号 0.95），但强度追不上 v4。v4 在条件特异性上
  的优势是**结构性的**（GBM 对 DNA 条件显式分裂 + 手工 160 维位点簇/电荷特征），DL 从原始
  token 学不出这个归纳偏置。

## 4. 用户拍板：互补组合 → 数据证明"好用" ★本阶段核心成果

用户："将他们组合一下互补使用，反正最后工具好用、有用就行。"

**互补性数据证实**（n100，v4×DL 共同覆盖 30 系统）：
- DL_act 与 v4_sep 预测的维度**几乎正交**（DL_act vs 真 sep rho 仅 +0.082）→ 强结合的候选
  未必特异，必须两维兼顾。

| 信号 | vs 真 sep rho |
|---|---|
| DL_act(S1) | +0.082 |
| DL_sep | −0.234 |
| v4_sep | +0.606（v4 强项）|
| **互补 min(DL_act, v4_sep)** | **+0.630（全组最高，超 v4 单独）** |
| 互补 乘积 dl_act×v4_sep | +0.562 |

**互补反例证明价值**：RD_POS（反向对照）DL 判其结合强（act 1.42 排序高）但真 sep 仅 0.01
（不特异）→ 单看 DL_act 会误判为高价值，**min 互补组合正确把它压后**；而已入选 MD 的
s13_c1 被组合排到第 2。这正是用户"特异 ssDNA 高结合 + 非特异不结合"的筛选逻辑被正确执行。

**互补分工定型**：
- **DL(A1)** 管结合强度：act / dual（它赢 v4 处）
- **v4(GBM)** 管特异性：sep（结构性优势）
- **组合推荐度 = min(rank(DL_act), rank(v4_sep))** —— 两维都高才推荐，单高被惩罚
