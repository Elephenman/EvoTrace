## 0. 一句话结论

**照三篇配方把 DL transformer 真训出来了（v5），但在当前标注量（1288 逐模型行 / 63 系统 / 151 cells）
下全面输给 160 维特征的 GBM（v4）——sep 甚至反相关、V2-A 上位性排序错误；这与三篇论文的隐含共识一致:
稀疏标签区间的正确尺寸是"预训练表征 + 浅层专用模型"，DL 要划算需要标签量上一个数量级或变体专属表征。**

## 3. 提名工作流交付（p2 式，可直接接 Boltz）

`combo_nomination_gbm.csv`: 3 背景 × 3 热点 × 词汇表内 AA = 27 候选 × 2 条件，UCB = sep + 0.5σ。
词汇表外 AA 会退化（哑变量全零）——提名必须限内。**两个矛盾标记**（模型 vs 去混杂直接证据）:
- M255M@s13_c1 排第 1，但去混杂边际 M255M = −0.118（最差）→ 交互项压过了可靠边际证据
- Y217R@s13_c1 排第 7，但去混杂判定 Y217R 是双锁削弱因子（0.12）
→ 生产版提名应"直接边际优先、模型补盲区"；矛盾候选恰好是下一轮 Boltz 的信息量最大点。
F88K@WT（#6）是真正的新假设: 读头决定性突变在 WT 背景的单点效应从未直接测过。

## 4. DL 何时划算（两条路，均已在手）

1. **变体专属表征**（p1 的 ESM-2 用法）: 现在 token 用 WT 上下文——63 系统 + 新候选跑
   `esm3_embed_cluster.py`（集群现成，~2000 序列 ≈ 1 array 作业）→ 每变体专属 ESM3 嵌入替换 WT 上下文。
   这是唯一不花 Boltz 算力就可能翻盘 v5 的改动。
2. **标签量 ×10**（p1 轮次循环）: Boltz 重扫 n=8→100/cell + 提名循环每轮 ~2000 模型（4090 ≈ 3.5h）。
   标签到 ~10⁴ 行后 DL 的容量优势才有意义（p2 的 2.8×10¹² 打分依赖的也是其预训练量级）。

## 5. 建议行动顺序

1. v4 GBM + 提名工作流作为现役（替换 gate v3 的 3 位点查找表）
2. 集群跑变体专属 ESM3 嵌入 → v5 重训（唯一低成本翻盘点）
3. Boltz n=100 重扫（灭噪声天花板，所有精度主张的前提）
4. 提名 top-5（含 2 个矛盾候选 + F88K@WT）进下一轮 Boltz 复核

## 6. v6 终验（2026-09-03 追加）—— 变体专属 ESM3 表征版

**数据**: sugon 集群新增 3126 个 ESM3 嵌入（105 训练系统全覆盖 + 3021 单点全空间, 4+2 作业）。
**改动**: 仅 token 上下文从 WT 共享嵌入 → 变体自身嵌入（v3 同款 PCA-64, ±2 窗口）；其余与 v5 严格一致。

| 指标 | v4 GBM | v5 DL(WT ctx) | **v6 DL(变体 ctx)** |
|---|---:|---:|---:|
| V1 act / dual / dcat LOO | **+0.638 / +0.718 / +0.705** | +0.552 / +0.682 / +0.639 | +0.576 / +0.680 / +0.650 |
| V1b sep 全量 / 符号 / top10 | **+0.150 / 0.83 / +0.652** | −0.232 / 0.76 / −0.151 | −0.226 / 0.76 / −0.039 |
| V3 V2-A 留出（真实 +0.25/−0.05） | **+0.120 / −0.011 ✓** | +0.958 / +1.372 ✗ | +0.953 / +1.325 ✗ |

**结论升级为三模型类稳健负结果**: 变体专属表征不改变任何维度。深度模型的失败是**结构性的、
专门发生在条件差分（sep）泛化上**——V1 绝对 act 水平它学得会（~0.58）, 但"该变体在靶 vs
非靶 DNA 上表现多不同"这个维度, 小样本 LOO 下它记忆系统身份而非条件差分行为; 树模型 +
强手工特征恰好捕获这一维度。三篇论文的模型都没有面对这个"条件差分泛化"难题（p1 的
ωRNA 是工程维度非打分维度）。

**DL 翻盘的剩余路径只有一条: 标签量 ×5**——n=100 重扫（CHPC job 225832, 7400 模型, 已排队,
GPU 释放后自动执行）落地后用 fetch_aggregate_n100.py 回收, 逐模型行从 1288 → ~7400,
且标签噪声半宽从 ±0.15 压到 ±0.07。届时 v5/v6 架构重训是首次公平测试。
在此之前, 现役 = v4 GBM + 组合提名工作流。
